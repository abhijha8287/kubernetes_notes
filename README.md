# Kubernetes Notes

Hand-written notes on Kubernetes and the distributed-computing ideas behind it.

## Why this exists
Notes taken while learning Kubernetes for MLOps work, kept in one plain-text file for quick revision.

## What it does
Covers, in order:
- Distributed computing: clusters, lead nodes, communication, concurrency
- How Kubernetes compares with Apache Spark (MapReduce)
- Benefits: scalability, fault tolerance, performance, cost
- Challenges of distributed systems
- Microservices, using a movie-recommendation ML system as the example
- Kubernetes internals, with a before-and-after analogy
- How Docker packages and Kubernetes orchestrates ML microservices
